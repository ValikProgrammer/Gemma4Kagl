# IDEAS

Идеи для роста счёта. Статус: `new` / `planned` / `testing` / `done` / `dropped`.
Источник фактов: `docs/analysis_v4.md`, `docs/research_competition.md`, `docs/harness_levers.md`.

## A. Измерение (база для всех решений)

1. `new` **Больше задач в смоуке.** 10 задач дают шум около ±15 п.п. Нужно 30–50 задач.
   Брать стратифицированно: fastapi, rich, requests. Фиксированный набор для всех версий.
2. `new` **Скрипт разбора прогона.** Один скрипт: таблица resolved, время, вызовы, пик запроса, exit_code.
   Тогда каждый разбор не тратит контекст агента.
3. `new` **Параллельные прогоны.** Много компьюта = несколько вариантов конфига одновременно.
   Один ноутбук на вариант, один фиксированный набор задач.

## B. Конфиг без обучения

4. `dropped` **include_thoughts: false** Отменено: абляции показывают, что `true` — главный плюс.
5. `new` **Модель 12B против 31B при том же времени.** 12B быстрее. Больше ходов за 8 минут.
   v2 на 12B упала из-за окна, не из-за качества. Нужен честный повтор.
6. `planned` **Жёсткий порядок работы в промпте:** найти файл → воспроизвести → править → прогнать тест → submit.
   Лимит чтения: после N чтений без правки — сделать правку или гипотезу.
7. `planned` **Время на задачу: 5 мин.** Лимит прогона 12 ч на ~116 задач. 8 мин = риск 0 за всю посылку.

## C. С обучением (когда будет компьют)

8. `new` (низкий приоритет: в обсуждениях нет стабильного плюса, декодинг −15–20%) **LoRA на траекториях.** Правила разрешают адаптеры до 3 GiB.
   Схема: прогнать 31B на многих задачах, оставить успешные траектории, дообучить.
   Данные: 129 публичных задач + внешние наборы (SWE-Gym, SWE-smith и т.п.), репо не fastapi/rich/requests.
   Риск: модель квантована (w4a16). Нужно проверить, что адаптер грузится в харнес.
9. `new` **LoRA на формат вызова инструментов.** Меньше битых tool calls, меньше лишних ходов.

## B2. Из разбора v4 (`planned`, входят в v5)

10. Аргументы без экранирования (`\"`, `\\n`): сломали 3/10 задач.
11. `grep -n` + узкое чтение, без повторов: 17 компакций ≈ 11% времени.
12. Убрать `agent_tool` и `search_similar_code`.
13. `max_output_tokens` 8192, `thinking_budget` 4096: так делают публичные конфиги.
